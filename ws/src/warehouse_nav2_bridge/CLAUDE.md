## モジュール構成（part 1 = nav2_bridge パッケージ）
- `core.py` — `Nav2BridgeCore`（**純 / no rclpy / no FastAPI**）：validate → backend.go_to、task_id 採番、`active_tasks`（threading.Lock）、`poll_results`（200ms 完了監視, 注入 clock で wait 期限も判定）。location→coord は**凍結 `locations`**（config==`warehouse_interfaces.locations.KNOWN_LOCATIONS`）。`via` は **WAYPOINTS 契約が未凍結のため同じ凍結 `locations` で検証**（doc12a:351 の WAYPOINTS 辞書は発明しない＝docs-first）。
- `backend.py` — `NavigatorBackend`(ABC) seam + `FakeNavigatorBackend`（テスト用）。core は rclpy/nav2 を import しない。
- `errors.py` — `Nav2BridgeError(error_code, detail, http_status)`（doc12a:345-363 の 6 コード ＋ `INVALID_GOAL`(400)＝#223 座標ゴール拡張: destination/goal の両方/両無 or 不正座標）。
- `app.py` — `create_app(core)`：FastAPI 5 endpoint（**fastapi は lazy import**＝core ユニットは非依存）。`Nav2BridgeError`→ `{status,error_code,detail}` + HTTP status を 1 つの exception handler で写像。`navigate` body は `destination`(名前) ＋ additive optional `goal`[x,y] のいずれか。
- `head_on_injector.py` — `HeadOnInjector`（**純 / no rclpy / no FastAPI / cross-track import なし**）：#223 座標スワップ直列化器。`navigator`（duck-typed `.navigate(robot,*,goal=)`）＋ `arbiter`（`SimpleTrafficManager` 形＝`submit_task`/`release_aisle`/`aisle_locks`, traffic_logic.py:159,165,190・**注入・import しない**）を受け、`head_on_goals` DATA を route_A 排他で直列化（先着 navigate→後着は入口待機→`on_goal_reached` で解放→後着 dispatch、doc11a:446/453/§9.3）。
- `nav2_bridge.py` — `BasicNavigatorBackend`（実 `BasicNavigator` ×bot, **lock 直列化**）+ rclpy ノード（200ms timer→ goal_result publish）+ `main()`（rclpy thread + uvicorn main、doc12a:200-219）。**runtime のみ**（unit 非対象＝AST スキャンでのみ検査）。**座標ゴールは backend `Pose=(x,y)` をそのまま通る（yaw 非対応のまま・`orientation.w=1.0`）**。**pip dep（`uvicorn`/`fastapi`/`pydantic`）は lazy**＝`main()` 冒頭の `require_runtime_deps()` が rclpy.init() より先に走る（#283）。`nav2_simple_commander` も `BasicNavigatorBackend.__init__` 内 lazy（module-level import は `rclpy` のみ）。／ `preflight.py` — **純 / no rclpy / no fastapi / no uvicorn**（＝この行の下に別 bullet を足すと `CLAUDE.md:19-21` を参照する doc11c:260・rmf_adapter/CLAUDE.md:23 が行ズレするため同一 bullet に同居。#165）：pip runtime dep の起動時 preflight。`probe_runtime_modules(importer=…)`（importer 注入可）/ `missing_runtime_modules` / `format_missing_hint`（**環境非依存の純関数**＝`.env` 値を起動ログに出さない、rules/safety.md。原因 `ImportError` の `name` が probe 対象と違う＝transitive dep 欠損なら `fastapi (its import failed on missing 'pydantic')` の形で真犯人も併記）/ `require_runtime_deps`→ 不足時 `SystemExit(hint)`（idiom は `warehouse_mcp_server/server.py:136-139`）。バージョン pin は **setup.py `install_requires` 単一ソース**（hint は pin を複製せず setup.py を指す）。

## 提供 (produce)
- **REST API** `http://127.0.0.1:8645`（doc12a:222-343。loopback=co-located MCP, safety.md）:
  - `POST /api/v1/navigate {robot, (destination | goal[x,y|x,y,yaw]), via?}` / `POST /api/v1/wait {robot,duration}` / `POST /api/v1/stop {robot}` / `GET /api/v1/status/{robot}` / `GET /health`
  - **#223 additive**: `navigate` は名前 `destination` に加え inline 座標 `goal`（x,y[,yaw]）を受理（XOR・両/両無は `INVALID_GOAL` 400）。座標は `_coord` を通さず backend へ直送・**yaw は drop**（backend `Pose=(x,y)`）。名前ゴールの応答は従来どおり（後方互換）、座標ゴールの応答は `{...,"destination":null,"goal":[x,y]}`。
- **lib**: `preflight.require_runtime_deps()`（#283）＝pip runtime dep 不在時に **actionable な provisioning hint 付きで `SystemExit`**（module 名＋`pip3 install --break-system-packages …`＋`deploy/dev/Dockerfile` 参照）。本パッケージ内 `main()` 専用（他パッケージは各自所有＝下記 TODO）。
- **lib**: `head_on_injector.HeadOnInjector`（#223）＝座標スワップ直列化器（produce 詳細は上記モジュール構成）。`scripts/slice3_inject_swap.sh`（live operator wrapper：`head_on_goals` DATA 導出→REST `/navigate` 座標 body→status-poll 直列化）。
- topic: `/nav2_bridge/goal_result`（std_msgs/String JSON `{robot,task_id,result}`）→ State Cache（doc12a:384-392）

- **datum yaw に declination / yaw_offset が乗る場合**: `navsat_transform.cpp:291-292` は `imu_yaw += (magnetic_declination_ + yaw_offset_ + utm_meridian_convergence_)`。03:58 の「磁気 yaw を使う場合のみ実値」を採ると runtime の回転は `R_z(−(datum_yaw + declination + yaw_offset))` になり、本 compile が焼く角度とズレる。route file には該当フィールドが無い（03:99-105）ので**発明せず残件**とした。
- **03:102 と 03:93-96 の読みの衝突（未解決・docs 側裁定待ち）**: 03:102 の表は `x / y / yaw` を「L3 compile で焼いた結果」とするが、`yaw` は 1 つしか無く、compile 出力として上書きすると**記録された方位が失われ compile が冪等でなくなる**（二重回転）。本実装は `yaw` を**記録値として保存**し、map frame の yaw は `bridge_goals` の戻り値でのみ返す（schema にフィールドを足さない）。
- **射程外（docs にスキーマが無いので作らない）**: keepout マスク（`allowed_area`）生成と横断点レジストリ（`crossing_id` の進入方位・灯器 ROI 等＝[08:66](../../../docs/mode-outdoor/08-architecture-v2-reference-alignment.md)）。GeoJSON / マスク生成は本追補に含めない。
