主張判定反映
Local Static Layer は rolling でも重ねられる誤った理由で正しい結論を守っていたdoc23 §2 の理由を訂正（Static の座は /map 再定義が継ぐ）
Keepout は両 costmap・Inflation は自動適用されない正02_Map_and_Route の keepout mask・06 の keepout filter（両方）
Isaac ROS 4.6 で Orin 対応・「Thor 専用」は更新要条件付き（結論不変）cuVSLAM の blocker は「ハード」でなく ADR-0008 の Humble pin（4.6 は JP7.2 / Jazzy 前提）
Nav2 Route Server は Humble に無い誤nav2_route 1.1.20 が humble backport 済（index.ros.org released）→ 02/05 の候補 A
differential は位置 + 姿勢・N−1 は目安正doc23 B-4 の「凍結」を緩和・GNSS は differential:false
Recovery は屋外初期版で無効に正06 の初期プロファイル・OQ-OD58 (c)
MCU watchdog は上位ソフトとは別に必要正（既に W-3 / ADR-0013）09 の W-3・OQ-OD86
