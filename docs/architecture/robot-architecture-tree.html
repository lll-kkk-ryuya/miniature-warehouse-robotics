一般形（外部レビュー案）M1 実構成での裁定正本
GNSS / RTK を Sensors に置く対象外（屋内ジオラマ・0.01m 地図でセル数個分・予算外。理由つきで ✗ 残置）doc23 §5-1
ros2_control を Control に置く非採用。メカナム逆運動学は STM32 ファーム側・ホストは自前シリアルドライバで body 速度を送るだけ02-hardware §残課題5-6

nvblox_layer を Local のみに置く偶然 T3 段と一致。TARGET 完成形は Global にも T4 で追加（ただし OQ-8 次第で T3 止めが現実解）doc23 §2・§7 移行順
cuVSLAM を確定要素として置く／cuVSLAM→Pose→nvblox 直結も可不採用確定 = blocked-by-hardware（2026-08-17。HP60C が IR/ステレオ不可 ＋ Humble 用 Isaac ROS 3.2 に depth 経路なし）。TARGET-1 は MOLA-LO（2D LiDAR odometry）へ置換し、TF を出さない EKF 第2入力（odom1）という形だけを引き継ぐ。直結（TARGET-alt）は Guardian 沈黙 + map 原点ズレの 2 blocker で不採用doc23 §5-3 ／【2026-08-17 追補】
TF ツリー（map→odom→base_link→sensor）形は同じ。本質はエッジごとの配信責任（AMCL / ekf_node / robot_state_publisher が各 1 ノード・launch 排他・unit pin）＋ camera_link は contract PR 要doc23 §5-2
（無し）Human Interaction08 を新設。gesture_detector は 04 と並列の第2ブランチ（Nav2 の下流ではない）。ER バイパスの決定論経路・既存 L3/L2 ゲートは全通過mode-x-er/09 / ADR-0007
